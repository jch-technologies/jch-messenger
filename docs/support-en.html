Frequently Asked Questions

I cannot log in

Make sure you are using the correct credentials. JCH Messenger is a closed system – an account must be set up by an administrator.

I forgot my password

Contact the administrator of your community. Self-service password reset is only possible through the administrator for security reasons.

Notifications are not working

Check the notification settings in your device's system settings and make sure notifications are enabled for JCH Messenger.

Delete account

Instructions for account and data management can be found on the Account Deletion page.
